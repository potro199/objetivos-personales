# Objetivos Personales

Página de colocación del mes de préstamos personales (Grupo Puerto) contra los objetivos 1, 2 y 3, con el promedio diario necesario para llegar a cada uno.

- `index.html` — la página (GitHub Pages). Pide clave al abrir.
- Los datos viven en el bloque `/*DATA-START*/ … /*DATA-END*/` de `index.html`. Los actualiza Claude todos los días hábiles a las 17:30 (hora de Buenos Aires) después de consultar Salesforce.
- `build.py` — referencia del cálculo (no se usa en producción).
